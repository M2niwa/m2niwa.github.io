ComfyUI 本地部署：国内网络下的镜像源与模型复用

2025-07-08

为了给游戏美术管线做本地图像生成，我在一台 Windows 11 + RTX 3070 8GB 的机器上装 ComfyUI。安装本身不复杂，但「包下载」「模型下载」和「模型格式」三件事在国内网络下各有各的坑，这里按踩坑顺序记录。

先对齐 Python 与 CUDA，再谈安装

机器上不止一个 Python：Windows Store 的 python3 和 Anaconda 各有一份，前者带着 CUDA 版 torch 2.6.0+cu124，后者是 CPU-only 的 torch 2.9.0。装完 raise 的一瞬间就真会问「为什么没有 GPU」，所以第一步永远是：

python3 -c "import torch; print(torch.cuda.is_available())"
# 务必输出 True 再往下走

接着是 torchaudio 的 DLL 兼容问题——Windows Store Python 的 torchaudio 2.11.0 加载 DLL 直接报 WinError 127。解决方式是让 torchaudio 与 torch 版本对齐到同一套 CUDA 轮子：

python3 -m pip install torchaudio==2.6.0+cu124 \
  --index-url https://pypi.tuna.tsinghua.edu.cn/simple \
  --extra-index-url https://download.pytorch.org/whl/cu124

仓库用 GitHub 直接克隆会超时，换 Gitee 的 ComfyUI 镜像做浅克隆即可：git clone --depth 1 https://gitee.com/mirrors/ComfyUI.git。装完依赖 python3 main.py --listen 0.0.0.0 --port 8188 启动，第一次会下载前端资源包，等 30 秒左右再用 curl -s http://127.0.0.1:8188/ 验证。

模型不是下载慢，而是格式不对

最耗时间的一环其实在模型。hf-mirror.com 能访问，但实测只有 165KB/s，4GB 的模型要下载七个钟头，直接放弃。ModelScope 的 snapshot_download 快是快，可拉下来的是 Diffusers 多文件格式（多个文件夹），ComfyUI 需要的是单文件 .safetensors checkpoint，格式对不上；openxlab 则需要账号密钥登录。

最终的可行方案分两条：一是浏览器直接开 hf-mirror.com 手动下载 .safetensors 放 models/checkpoints/；二是如果手上已经有秋叶 WebUI Forge 整合包（我那台机器 D 盘就有 sd-forge-aki），直接 cp 复用模型，零下载：

# checkpoint → models/checkpoints/，text encoder → models/clip/，VAE → models/vae/
# 注意：Flux 的 unet 必须放 models/unet/，放 checkpoints 里不会被识别
cp /d/Documents/sd-forge-aki/.../models/Stable-diffusion/*.safetensors \
   /d/comfy/ComfyUI/models/checkpoints/
mv /d/comfy/ComfyUI/models/checkpoints/flux1-dev-bnb-nf4-v2.safetensors \
   /d/comfy/ComfyUI/models/unet/

8GB 显存下 nf4 量化的 Flux dev 能稳定跑 20 步，动漫向用 Animagine XL 4.0 fp8。装完之后回头看，唯一的「硬知识」其实只有两条：torch 的 CUDA 版本必须全链对齐，以及 ComfyUI 对模型目录有严格要求——其余时间都花在等下载上了。
