# 沧澜废舰 · 海洋废土背包乱斗 Roguelike

以《The Bazaar》（背包乱斗）为蓝本、以《沧澜废舰》海洋废土世界观为背景的单人 Roguelike 拾荒远征。纯原生 HTML/CSS/JavaScript，无依赖，双击 `index.html` 即可游玩。

## 世界观速览（依据《沧澜废舰》核心设定）

- **背景**：联邦星历 12327「大断连」后，海洋行星艾瑟瑞亚沦为废土：核心海域六大势力割据，外围「遗忘海域」遍布联邦遗迹与失控 AI。
- **你的身份**：自由锚地聚落的拾荒者——驾驶潮纹木船体，在督府、铁穹重工、环海自治联盟、北境冰封军阀与圣汐教会的夹缝中打捞、交易、战斗。
- **敌人势力**：督府巡逻队（制式合金）、锚地劫掠队（拾荒海盗）、铁穹军火商队、督府精锐、自治联盟特遣队、军阀冰封舰队；最终 BOSS 为北境军阀总旗舰「冰冠号」。
- **资源风味**：潮纹木（原文档注记「沧澜木」待改名，此处采用潮纹木，教会称「神赐圣木」）、星核合金、深海冷凝核心、超导结晶、STC 蓝图，以及传说遗物「源核芯片」（遗迹级超级 AI）。

**像素风渲染**：世界画面渲染到 1/3 分辨率的离屏缓冲再硬边放大（`imageSmoothing` 关闭），扁平配色 + 抖动网格 + 1px 硬描边 + 像素粒子/爆炸/准星；UI 为方块硬阴影皮肤 + CRT 扫描线；中文标签走全分辨率通道保持可读。

## 核心循环（每天 13 个节点）

```
（事件×3 + 小战斗）×3，最后一场大战斗关卡
```

- **事件节点**：从 8 类事件中 4 选 1（选定不可返回），进入后单次选择（仅商人可多买、多买后离开）；
- **战斗节点不可选敌**：小战斗遭遇随机敌舰队、**必定掉落**战利品（积累成长）；大战斗是**关卡考验**（随天数升级），第 5 天大战斗 = 最终 BOSS，胜利即通关，可继续无尽模式；
- 旗舰沉没或撤退 = 战斗失败，进入**战败结算界面**（坚持天数/击沉数/战斗数/金币/**总分**，历史最高分与最远航程），可再次远征或返回主菜单。

## 事件系统（两层 4 选 1）

**第一层：事件节点** —— 从 8 类事件中 4 选 1：

| 事件类型 | 内容 |
| --- | --- |
| 🛒 商人 | 进入随机商人界面（见下），可多买 |
| ⚔ 遭遇战 | 与遭遇的敌舰队交战，**无法挑选敌人**，奖励更丰厚 |
| 🎁 宝藏 | 发现战利品，四选一拿走 |
| 💰 发现金钱 | 安全/赌博/高风险等多种处置方式 |
| ⛽ 补给基地 | 付费的永久改装服务（装甲/船体/轮机/补给） |
| 🪝 神秘残骸 | 高风险打捞 |
| 🏕 雇佣兵营地 | 免费招募僚舰 |
| 🏋 训练场 | 四选一永久强化芯片 |

**每轮（每天）保证至少刷新一位随机商人。** 事件选定后不可返回；除商人（可买多件）外，所有事件均为单次选择。从船舱返回会回到当前轮次的节点页面（路由同步）。

**第二层：商人界面** —— 9 类商人各自专卖，各 4 件商品（价格随价值浮动，可购买多件）：

- ⚔ **军火贩子**（全部武器）· 💣 **重炮行商**（弹道火炮）· 🚀 **鱼雷行商**（鱼雷/导弹）· 🛡 **近防军火商**（近防与拦截装备）
- 🚢 **船坞掮客**（僚舰）· 🛳 **船体图纸贩子**（舰体图纸）· 🔧 **装配工坊**（舰船插件）· 🏺 **遗迹拾荒商**（遗物）· 🧰 **杂货铺**（消耗品与强化芯片）

## The Bazaar 式机制

- **船舱（背包）严格限容**：初始 4 格，每过一天 +1（上限 8），「扩容货舱」遗物可再 +2。超容时必须丢弃旧物品才能拿新物品。
- **物品总量随等级提升**：船舱容量随天数增长；遗物槽第 3/5 天各解锁一格；僚舰槽第 3 天解锁第二格；OP 上限可通过升级芯片持续扩充。
- **奖励物品类型**：
  - ⚔ 武器（装备到舰体槽位，消耗 OP）
  - 🔧 舰船插件（消耗 OP，与武器共享点数池）
  - 🚢 僚舰卡（编入 1~2 艘 AI 僚舰）
  - 🛳 舰体图纸（驱逐舰 → 轻巡 → 重巡 → 战列舰，改装时武器尽量迁移）
  - ⬆ 永久强化芯片（OP/耐久/装甲/航速/散热/热容/伤害……可叠加）
  - 🏺 遗物（占用遗物槽的强力被动）
  - 🧰 战斗消耗品（战斗内按 6/7/8 使用）
- **金币经济**：战斗与事件获得金币，黑市购买、船坞付费升级、船舱里可出售物品。

## 战斗

沿用海战引擎：散热/热容、OP 装配、武器分组与自动开火、水面阻力、鱼雷拦截、装甲剥蚀。

- **横推机动（Q/E）**：前进最快 > 倒车其次 > 横推最慢；小船三速差距小，大船横推与前进步差悬殊。
- **伤害类型**：武器分为高爆/动能/破片/光束四种——**动能对盾 2×、高爆对盾 0.5×、破片对盾 0.25×、光束 1×**；对装甲则反过来：高爆 2×、动能/破片 0.25×、光束 1×。用动能炮拆盾、高爆弹撕甲、破片打裸船体，才是效率最高的打法（武器卡上有颜色标签与倍率提示）。
- **OP 调校**：剩余 OP 可投入冷凝循环（每级 +8 散热/5OP）、热阱扩容（每级 +120 热容/4OP）、损管护盾（每级护盾系数 -0.08/6OP），OP 不再浪费。
- **损管护盾（X 开关）**：护盾本身没有容量——开启时承受的伤害按系数（默认 ×1.0，调校/插件/遗物可降至最低 ×0.5）折算为**热量**：0.42×对盾倍率进**软热量**（散热可排空）、0.28×对盾倍率进**硬热量（硬损伤）**；**开盾有维持成本**（每秒消耗 1%×系数 的热容，进软热量）；总热量 = 软 + 硬，触及热容上限触发**指挥过载**。硬损伤单独着色、占据总热量，护盾开启期间不会消散，关闭护盾后也要**等软热量散尽（先软后硬）才开始缓慢消退**（0.6×散热/秒）；护盾关闭或过载时伤害直击船体。**所有舰船默认自带系数 1.0 的护盾**。
- **主动散热（V，远行星号式）**：高风险高收益——开启后**不可中断、强制关盾、无法开火**，**持续到完全散热为止**：软热量以 6 倍速度排空，软热量散尽后硬热量也以散热速度消散（先软后硬），全部排空才结束（热量越少散热越快）；散热中被集火就是靶子，请选择安全窗口再按 V。
- **武器经济**：占位型廉价武器（铁管喷枪/铆钉枪/掷弹筒，1~3 OP）绝对性能差但每 OP 性价比极高，商人「清仓货架」常驻半价；单槽位高级武器（湮灭者长矛/星核粉碎炮/螺旋穿甲鱼雷，传说级）性价比低但吃满大型槽位的输出潜力。
- **异形舰体**：双舟级双体舰（cat）、巨锤级锤头舰（T）、星枢级十字舰（cross）、折戟级 L 形强袭舰（L），槽位布局与机动参数各不相同。
- **舰船 AI（远行星号式）**：五种舰长性格（鲁莽/激进/稳健/谨慎/怯懦）决定交战圈与撤离余量；目标选择优先可破防/残血/距离，并会**优先集火护盾关闭、过载或快过载的敌舰**（无盾/过载/热量>85% 都视为收割窗口压上）；**接近与追击时蛇形横推摆动**，不会锁死航向死直冲锋；**战斗姿态用横推平移环绕**（远行星号 StrafeTargetManeuver）——舰首炮为主的船舰艏直指目标侧推平移接舷，炮塔为主的船保持舷侧角环绕走位，贴脸时倒车+侧滑拉开；危险后撤有明确撤离距离（敌方最远射程 + 性格余量），倒车或斜向脱离时舰艏始终朝敌继续开火，到点即停，绝不背对敌人无限逃跑；目标散热/过载时压上收割，高压（热量>78%，或刚挨打且热>60%，对应原版 flux>0.7 后撤 + 被打威胁×3）或无法破防时外推交战圈；**弹道规避按轨迹预判**（远行星号 CollisionAnalysisModule 风格）——对每枚来袭弹体求最近点距离，只有真正会命中的才躲（子弹/能量弹/鱼雷/制导导弹全覆盖），规避方向垂直弹道把船推离弹道线并兼顾作战方向，护盾完好时无视可吸收的子弹，连续规避超时则接受风险；**AI 也会管理自己的护盾**——过载失能或脱离敌方射程且最近没挨打时主动关盾让硬损伤消散（来袭伤害期间保持护盾），重新接战且硬损伤基本消退后再开盾；危险只看船体血量，护盾不参与危险判定。
- **鱼雷 / 导弹 / 爆炸模型**：导弹是空中目标，近防炮与光束都能拦截；**鱼雷走深水**——只有光束能拦截「浅层」（靠近 260px 内）的雷，且**深水鱼雷对吃水不足的小艇无效**（吃水：侦察艇/双体舰/强袭舰=1，护卫舰/锤头舰=2，巡洋/十字舰=3，战列舰=4；鱼雷潜深：533=1/610=2/800=3）；爆炸类武器（鱼雷/导弹/高爆弹）按**近炸引信**结算：进入引信半径即引爆，范围伤害中心全额、边缘 30% 衰减，注意误伤友军；**鱼雷/导弹有高额直击穿透**（533=50%/610=55%/800=60%，导弹 35-45%）——直击时按比例绕过护盾直接打船体，护盾只吸收剩余部分，让拦截与规避更有价值。
- **航母与载机**：天舟级轻型航母提供 2 个机库位，**载机像武器一样装配**（燕隼拦截机/海鸥护航机/信天轰炸机，各成小队）；载机**没有舰船碰撞体积**（可穿越船队），但会被子弹、光束灼烧、爆炸波及；母舰有**整备值**（0-100，缓慢恢复）：返航整备（弹药/维修免费）期间整备值停止恢复，**补充战损载机消耗整备值**，整备值越低整备/发射越慢。
- **战斗 HUD**：光标由舰心延伸出瞄准线，线上有分段式过热条；选定武器组在射程上画出射界圆弧并编号（奇数时编号偏左）；自船半透明状态框跟随自船，锁定目标状态框跟随目标。

- 小/大战斗各 4 个敌方舰队可选（威胁 2~8 星），威胁越高金币与掉落越丰厚；
- 敌军规模与 AI 随天数成长：AI 反应速度从 0.5s 逐渐逼近人类水平（始终略慢半拍）；
- 战利品稀有度（普通/稀有/史诗/传说）随天数提升。

## 战斗操作

| 按键 | 功能 |
| --- | --- |
| W/S、A/D | 前进倒车、转向 |
| 按住右键 | 自动航向 |
| 左键 | 开火 / 点击敌舰锁定 |
| 1~5、F | 选武器组 / 组自动开火 |
| V | 主动散热 |
| 6/7/8 | 使用消耗品 |
| Tab/R、空格、滚轮 | 锁敌、暂停、缩放 |
